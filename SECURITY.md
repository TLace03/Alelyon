# Security policy

## Reporting a vulnerability

Please report a vulnerability **privately**, through GitHub: open this repository's **Security** tab and choose
**Report a vulnerability** (a private security advisory). Do not open a public issue, pull request or discussion for
it.

Please include what is affected (file, version or commit), how to reproduce it, and what an attacker gains. We will
acknowledge the report, keep you informed, and credit you in the advisory unless you ask us not to.

## Scope

In scope: the code and files in this repository, and the open modules it is assembled from
([Alelyon-Client](https://github.com/TLace03/Alelyon-Client) and [Alelyon-OS](https://github.com/TLace03/Alelyon-OS),
which take reports the same way).

Alelyon's hosted services are not in this repository, but a vulnerability in them that you find through the app is
welcome through the same private channel.

Please do not test against other people's accounts, try to degrade a service, or run automated scans against
Alelyon's production services.

## Supported versions

Only the latest export on the default branch is supported.
